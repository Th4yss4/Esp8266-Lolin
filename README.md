# Esp8266-Lolin

Projeto para desenvolvimento com a placa Lolin baseada no ESP8266, um microcontrolador com conectividade Wi‑Fi integrado.

## Sobre o `index`

O arquivo `index` normalmente é a página inicial da interface web do projeto. Quando o ESP8266 funciona como servidor, ele envia esse arquivo ao navegador quando o usuário acessa o endereço da placa. Nele ficam a estrutura e o conteúdo da tela, como textos, botões e controles usados para acompanhar ou comandar o dispositivo.
